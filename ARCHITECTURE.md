# Architecture

## Обзор

Это статическое PWA без backend. Приложение открывается как обычный сайт и может быть установлено на iPhone через Safari. Основной сценарий сейчас один: главный экран лунного календаря для Москвы.

## Основные файлы

- `index.html` содержит разметку главного экрана и PWA-подключения.
- `src/styles.css` отвечает за визуальный стиль, адаптацию под мобильный экран и карточки данных.
- `src/app.js` собирает данные из расчетных модулей и обновляет DOM.
- `src/format.js` форматирует дату и время в московской зоне.
- `src/astro.js` содержит базовые fallback-расчеты: фаза Луны, планетарный день, планетарный час, примерная Луна без курса.
- `src/preciseEphemeris.js` читает предрасчитанные Swiss Ephemeris данные и возвращает точные события.
- `src/ephemeris-data.js` хранит сгенерированные данные на 2026-2030 годы.
- `src/dayIndicators.js` считает лунный символ, Ба-цзы день и индикатор дня Tong Shu. Для Tong Shu используется московское время, Jie Qi месяц и смена энергетического дня в 23:00.
- `scripts/generate-ephemeris.cjs` генерирует Swiss Ephemeris данные.
- `sw.js` кэширует приложение как PWA.

## Поток данных

1. `src/app.js` берет текущее время.
2. Для точных лунных событий сначала используются данные из `src/preciseEphemeris.js`.
3. Если точных данных нет, часть значений берется из fallback-расчетов `src/astro.js`.
4. `src/dayIndicators.js` получает лунный день и солнечный месяц, переводит дату в московский энергетический день со сменой в 23:00, затем возвращает показатели дня.
5. `src/app.js` форматирует значения и обновляет элементы на главном экране.

## Точные данные

Swiss Ephemeris используется не в браузере, а на этапе генерации. Скрипт `scripts/generate-ephemeris.cjs` создает:

- переходы Луны по знакам;
- интервалы Луны без курса;
- мажорные аспекты Луны к планетам;
- точные новолуния и полнолуния;
- границы лунных дней для Москвы;
- китайские солнечные месяцы.

Результат сохраняется в `src/ephemeris-data.js` и попадает в статическую сборку.

## PWA

`sw.js` использует cache-first стратегию для статических файлов. При изменениях, которые должны гарантированно появиться на iPhone, нужно поднимать `CACHE_NAME`.

Текущая версия кэша: `lunar-calendar-v15`.
