# Лунный календарь PWA

PWA для iPhone с главным экраном лунного календаря для Москвы.

## Что показывает

- текущую дату, день недели и живые часы;
- лунный день и фазу Луны;
- Луну без курса;
- планетарный день недели;
- текущий планетарный час и его временной диапазон.

## Запуск локально

```bash
npm test
python3 -m http.server 4173
```

Открыть: `http://localhost:4173`.

## Установка на iPhone

После публикации откройте URL приложения в Safari, нажмите `Поделиться`, затем `На экран "Домой"`.
