# Лунный календарь PWA

PWA для iPhone с главным экраном лунного календаря и астрологических показателей для Москвы.

## Что сейчас работает

- текущая дата, день недели и живые часы;
- лунный день для Москвы;
- обычная фаза Луны;
- точное `Новолуние в HH:MM:SS` или `Полнолуние в HH:MM:SS` в день события;
- знак Луны и следующий переход в знак;
- Луна без курса;
- последний и следующий мажорный аспект Луны;
- аспект, после которого Луна уходит без курса;
- качество поля: одна фраза момента и три практические оценки;
- лунные сутки по эзотерической традиции;
- Ба-цзы день;
- индикатор дня Tong Shu по выбранной линии расчета: MSK, Jie Qi, смена энергетического дня в 23:00;
- планетарный день недели;
- текущий планетарный час и его временной диапазон;
- установка на экран iPhone через Safari.

## Текущие ограничения

- город жестко задан как Москва;
- будущие экраны календаря, планет, знаний и настроек пока не реализованы;
- индикатор дня Tong Shu требует дополнительных контрольных дат выбранной школы на 2026-2030 годы;
- приложение рассчитано как статический GitHub Pages сайт без backend.

## Данные

Точные лунные события предрассчитаны через Swiss Ephemeris и сохранены в `src/ephemeris-data.js`.

Сейчас в данных есть:

- переходы Луны по знакам;
- Луна без курса;
- мажорные аспекты Луны к планетам;
- лунные дни для Москвы;
- новолуния и полнолуния;
- китайские солнечные месяцы.

## Запуск локально

```bash
npm test
python3 -m http.server 4173
```

Открыть: `http://localhost:4173`.

## Обновление эфемерид

```bash
npm run generate:ephemeris
```

После изменения файлов, которые кэшируются PWA, нужно поднять `CACHE_NAME` в `sw.js`.

## Калибровка качества поля

```bash
npm run calibrate:field
```

Скрипт печатает контрольные даты, фразу поля, три оценки, исходный контекст и причины. Он нужен для настройки весов и формулировок без изменения интерфейса.

## Установка на iPhone

После публикации откройте URL приложения в Safari, нажмите `Поделиться`, затем `На экран "Домой"`.

Если на iPhone видна старая версия, нужно обновить Safari/PWA-кэш или дождаться, пока service worker установит новую версию.
