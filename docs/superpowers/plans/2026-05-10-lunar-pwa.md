# Lunar PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an installable iPhone PWA that renders the reference-style lunar calendar home screen and calculates all displayed values locally for Moscow.

**Architecture:** Use a dependency-light static app: `index.html`, focused CSS, ES modules for rendering and calculations, and Node's built-in test runner. Calculation modules stay separate from DOM rendering so behavior can be tested without a browser.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Web App Manifest, Service Worker, Node `node:test`.

---

## File Structure

- `package.json`: scripts for tests and local preview.
- `index.html`: PWA shell and root container.
- `manifest.webmanifest`: iOS/PWA metadata.
- `sw.js`: offline cache service worker.
- `src/styles.css`: reference-matching responsive visual design.
- `src/app.js`: live clock/render loop and DOM binding.
- `src/astro.js`: lunar, planetary day/hour, sunrise/sunset, and void-of-course calculations.
- `src/format.js`: Russian labels and Moscow date formatting helpers.
- `test/astro.test.js`: calculation tests.
